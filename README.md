# WOODCRAFT

Лендинг мебельной мастерской: тёмная страница, фон из папоротника и два интерьерных кадра. Вёрстка повторяет макет — шапка, первый экран, блок о студии, четыре причины, форма заявки и подвал.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://127.0.0.1:4317](http://127.0.0.1:4317).
